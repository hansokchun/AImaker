# 배포 전 최종 체크리스트

이 문서는 일픽의 공개 출시 기준입니다. 앞으로 아래 7개 단계의 이름과 순서는 바꾸지 않습니다. 완료한 항목만 `[ ]`에서 `[x]`로 변경하고, 새 항목은 해당 단계의 `추가 항목`에 적습니다.

현재 상태: 2026-07-20 기준

## 1. 관리자·의뢰자·전문가 실제 화면 QA

- [x] 관리자, 일반 사용자, 판매자 기능 화면 접근
- [x] 프로필 수정 및 이미지 업로드 화면 확인
- [x] 상품 등록, 상담, 제안, 작업방 주요 화면 확인
- [x] Toss 테스트 결제 후 작업방 생성 확인
- [x] 정산 신청 및 관리자 수동 정산 화면 확인
- [ ] 새 상품 1개 실제 등록 후 공개 화면 노출 확인
- [ ] 실제 취소·환불 흐름 1건 확인
- [ ] 실제 은행 송금 후 관리자 `지급 완료 처리` 확인

### 추가 항목

- [x] `일픽` 공식 로고 에셋(헤더용, 푸터용, 파비콘/공유용) 확정 및 적용
- [x] 헤더·푸터·로그인·온보딩·관리자·핵심 거래 화면의 브랜드명과 로고 적용
- [x] 일픽 로고 톤의 상품 상세 페이지 디자인 시안 적용 및 데스크톱 확인
- [x] 전역 색상 토큰과 기존 고정 색상을 일픽 네이비·블루 팔레트로 통일
- [ ] 데스크톱·모바일에서 로고 크기, 명도 대비, 버튼·링크 강조색을 일픽 네이비·블루 기준으로 화면 QA

- [x] 운영 키가 없을 때 테스트 키를 자동으로 사용하는 예비 코드 제거
