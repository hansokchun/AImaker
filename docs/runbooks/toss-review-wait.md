# Toss Payments 심사 대기 실행표

기준일: 2026-08-10

## 심사현황 확인

1. [토스페이먼츠 상점관리자](https://app.tosspayments.com/)에 신청 계정으로 로그인합니다.
2. 왼쪽 메뉴에서 `PG`를 선택합니다.
3. `신청 현황`의 원코리아 항목에서 계약·입점 및 카드사 심사 상태를 확인합니다.
4. `보완 요청`이 표시되면 요청 사유와 제출 기한을 캡처하고, 대표자 본인인증·사업자등록증·사업용 통장 등 요청된 자료만 제출합니다.

계약 전에도 상점관리자에서 작성 중이거나 심사 중인 전자계약 내역을 조회할 수 있습니다. 로그인 후 주소가 바뀔 수 있으므로 위 상점관리자 첫 화면을 기준 주소로 사용합니다.

## 심사 중 미리 완료할 일

- [x] 사업자정보·고객센터·개인정보 책임자 정보를 사이트에 반영
- [x] 테스트 결제·취소·환불과 수동 정산 리허설
- [x] 최신 푸터와 Toss 심사 대기 상태를 `main`에 푸시
- [ ] Toss 보완 요청을 매일 1회 상점관리자·이메일·문자에서 확인
- [ ] 통신판매업 신고를 진행하고 신고번호가 나오면 사이트에 반영
- [ ] 환불·부분환불·분쟁 기준을 최종 승인
- [ ] 이용약관·개인정보처리방침의 초안 표시를 제거할 수 있도록 최종 검토
- [ ] AI 결과물의 저작권·상업 이용·사용자 책임 기준을 최종 승인
- [ ] Supabase Pro 전환 또는 암호화 수동 백업·복원 리허설 중 하나를 선택

## 운영 키 발급 직후 실행 순서

1. 운영 클라이언트 키를 Cloudflare Pages 환경변수에 등록합니다.
2. 운영 시크릿 키를 Supabase Edge Function Secret에 등록합니다.
3. Toss 상점관리자에 운영 웹훅 주소를 등록합니다.
4. 상점 노출명을 `기그온`으로 확인합니다.
5. 운영 도메인에서 소액 결제 1건, 실패 복귀 1건, 전액 취소·환불 1건을 검증합니다.
6. 결제·주문·작업방·환불 원장의 금액과 상태가 모두 일치하는지 확인합니다.

운영 시크릿 키는 채팅·문서·Git에 입력하지 않습니다. 등록 화면에서 직접 넣고 키의 앞뒤 일부만 가린 상태로 확인합니다.

## 보완 요청 대응 원칙

- 사이트 정보와 사업자등록증의 상호·대표자·사업자등록번호·주소는 법정정보 기준으로 일치시킵니다.
- 푸터의 접힌 사업자정보에 법정 대표자가 표시되어 있어야 합니다.
- 플랫폼 구조, 개인 전문가 입점, 수동 정산 방식은 사실대로 설명합니다.
- 지급대행 또는 보증보험이 별도로 필요하다는 답변을 받으면 결제 공개 전에 조건과 비용을 확정합니다.
- 보완 요청 내용이 불명확하면 토스페이먼츠 고객센터 `1544-7772` 또는 `support@tosspayments.com`으로 신청 사업자번호와 함께 문의합니다.
