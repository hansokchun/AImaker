# 대표자 출시 입력표

기준일: 2026-07-22

아래 값을 위에서부터 확정하면 Codex가 사이트·Cloudflare·Supabase·Toss 설정에 순서대로 반영합니다. 비밀번호와 시크릿 키는 이 문서나 Git에 적지 않습니다.

## 1. 사업자·고객센터

- 고객센터 이메일: 미정
- 고객센터 전화번호: 미정
- 운영시간: 미정
- 개인정보 보호책임자 이름: 태영호(변경 시 사업자·정책 문서 일치 확인)
- 개인정보 보호책임자 이메일: 미정
- 통신판매업 신고번호: 신고 전

완료 후 반영 위치: 푸터, 이용약관, 개인정보처리방침, Toss 심사 정보.

## 2. 수동 정산 운영

- 정산 담당자: 미정
- 지급 요일·주기: 미정
- 사업용 출금 계좌 준비 여부: 미정
- 이체 확인번호 기록 담당: 미정
- 분쟁 거래 보류 승인자: 미정

권장 시작안: 매주 1회 지급, 관리자 화면의 정산 신청·계좌·금액을 대조한 뒤 은행 이체, 이체 확인번호 기록 후 지급 완료 처리.

## 3. 도메인

- 최종 도메인: 미정
- 구매처: 미정
- `www` 사용 여부: 미정
- 명칭 충돌 검토: 2026-07-26 KIPRIS의 `긱온` 정확 일치 간이검색 결과는 없지만, [`gigon.ai`](https://www.gigon.ai/)와 [`gigon.io`](https://gigon.io/)가 동일 영문명·유사 중개 서비스를 운영 중이므로 상표 전문가의 지정상품 유사 판단 전까지 미완료
- 구매 후보: `gigon.kr`, `gigon.co.kr` (DNS 미설정만 확인됨. 실제 등록 가능 여부는 구매처에서 재확인)

도메인 구매 후 Codex가 Cloudflare Custom Domain, Supabase Site URL/Redirect URL, Google OAuth 승인 주소, Toss 성공·실패 URL을 같은 주소로 맞춥니다.

## 4. Toss 운영 전환

- 운영 계약·심사 상태: 미정
- 운영 클라이언트 키 발급: 미정
- 운영 시크릿 키 발급: 미정
- 운영 웹훅 등록: 미정

키는 채팅이나 문서에 붙이지 않고 Cloudflare Environment Variables와 Supabase Edge Function Secrets에 직접 저장합니다.

## 5. 실제 리허설

- `[출시점검]` 상품 1개 등록
- 의뢰자 계정으로 소액 결제 1건
- 외부 폴더 링크로 초안·수정본 제출
- 의뢰자 승인 1건
- 취소·환불 1건
- 전문가 정산 신청과 실제 은행 송금 1건
- 관리자 지급 완료 처리와 이체 확인번호 기록

실제 돈이 움직이는 결제·환불·송금은 대표자 확인 후 진행합니다.
