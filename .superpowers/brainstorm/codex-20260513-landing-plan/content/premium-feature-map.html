신뢰 중심 프리미엄 런칭 기능 맵

처음 공개 버전은 “멋진 기능 수”보다 “의뢰자가 맡겨도 되겠다, 전문가가 활동해도 되겠다”는 신뢰를 만드는 데 집중합니다.

Launch Target C

1. 탐색/발견

의뢰자가 좋은 전문가를 빠르게 찾는 영역

런칭 필수
전문가 목록/필터/정렬분야, 가격, 평점, 최신순
런칭 필수
전문가 상세 프로필소개, 도구, 패키지, 포트폴리오
런칭 후
검색 자동완성키워드 추천과 인기 검색어

2. 신뢰/검증

프리미엄 런칭의 핵심 차별점

런칭 필수
전문가 승인 상태검수 대기/승인/반려
런칭 필수
리뷰/평점의뢰 완료 후 작성 가능
주의
뱃지/랭킹운영 기준 없이 넣으면 신뢰를 깎을 수 있음

3. 의뢰/거래

실제 프로젝트가 시작되는 흐름

런칭 필수
요청서 작성/게시판의뢰자가 공개 모집
런칭 필수
패키지 기반 직접 문의초기 결제는 수동/문의 기반
런칭 후
자동 결제/에스크로법무/정산 설계 이후

4. 소통/진행

의뢰자와 전문가가 일을 진행하는 공간

런칭 필수
문의/메시지실시간이 아니어도 기록형으로 시작 가능
런칭 필수
프로젝트 상태대기/진행/전달/완료
런칭 후
실시간 채팅알림과 읽음 처리 포함

5. 회원/대시보드

각 사용자가 자기 일을 관리하는 영역

런칭 필수
마이페이지 탭 구조프로필, 프로젝트, 알림
런칭 필수
전문가 프로필 편집포트폴리오와 승인 상태 표시
런칭 후
정산 관리결제 도입 후 확장

6. 운영/법적 안전

프리미엄 런칭에서 빠지면 위험한 영역

런칭 필수
관리자 기본 화면회원/전문가/요청/신고 관리
런칭 필수
약관/개인정보/신고온보딩 동의 포함
런칭 후
운영 지표 대시보드전환율, 거래액, 활성 사용자
추천 진행 방식: 먼저 6개 분야를 확정한 뒤, 각 분야를 페이지 단위로 풀어냅니다. 그 다음 “런칭 필수 / 베타 이후 / 과감히 제외”로 쪼개면 개발 계획이 선명해집니다.
